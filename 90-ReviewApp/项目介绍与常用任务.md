# 90-ReviewApp 背词系统 — 项目介绍与每日常用任务

> 每天要操作什么、命令是什么，都看这份。完整规格见 [[CET6_Review_Task.md]]。

## 这是什么

Obsidian「脑记」vault 里的 CET6 背词工具：词库是 `10-Words/*.md`（2345 条，frontmatter 驱动），
纯本地、无服务器，每天生成一个单文件 `review.html`，浏览器里背词后导出 session JSON，
按 **SM-2 算法** 同步回对应 `.md` 的 frontmatter（`mastery` / `due` / `interval` / `ease` / `reviews` / `last-review`），
并推进 `progress.json` 的新词游标。复习逻辑与 `review.py` / Kotlin 端一致。

练习形式：遮词卡片 → 看英选中 → 看中选英 → 拼写 → （错词/复习词必出，新词 15% 概率）挖空造句题。

## 核心文件

| 文件 | 作用 |
|---|---|
| `build_review.py` | 每日构建：算到期复习词 + 游标起的新词 → 写 `sync/day_*.json` → 渲染 `review.html` |
| `sync_session.py` | 把导出的 `session_*.json` 同步回笔记（SM-2 + 推进游标），带 `--dry-run` |
| `organize_sync.py` | 把散落的 day/session 归档到 `sync/月份/第N周/`，定期跑 |
| `progress.json` | 游标 `cursor_index`、每日上限、学习历史 |
| `review.html` / `template.html` | 当日页面（构建产物）/ 模板源 |
| `config.local.json` | DeepSeek API key（已 gitignore，勿提交） |
| `sync/cloze_cache.json` | 挖空例句缓存（key=word，同词同天不重复调用） |

## 每日流程（背完一天，三步）

假设今天是 D，你要同步 D 的进度并生成 D+1 的词表：

1. **同步**（把 D 的 session 写回笔记，推进游标）：
   ```bash
   cd 90-ReviewApp
   python3 sync_session.py            # 同步 sync/ 里最新的 session_*.json
   ```
   想先预览可以 `python3 sync_session.py --dry-run`。
   > **找 session 的顺序：先查 `sync/`，没有再查 `~/Downloads`**（浏览器可能把导出存到下载目录）。
   > 在 Downloads 找到后先移回 `sync/` 顶层再同步，归档才不会漏。
2. **生成明天**（D+1 的词表 + HTML，构建期自动生成挖空例句）：
   ```bash
   python3 build_review.py --date D+1   # 例：--date 2026-08-17
   ```
3. **归档**（把 D 的 session 和 D+1 的 day 收进 `sync/2026-08/第3周/`）：
   ```bash
   python3 organize_sync.py
   ```

然后双击 `review.html` 就是明天的词表。

## 其他常用命令

- `python3 sync_session.py --file path/session.json` — 指定文件同步（session 不在 sync/ 顶层时用）
- `python3 build_review.py` — 不指定日期 = 按系统当天生成（明天用就加 `--date`）
- `python3 build_review.py --mock` — 离线演示，不调 API
- `python3 build_review.py --dry-run` — 只打印当天会取哪些词
- `python3 organize_sync.py --dry-run` — 预览归档
- 复现历史某天：`python3 build_review.py --date 2026-08-16 --cursor 204 --no-shuffle --seed 0`

## 关键约定（别踩坑）

- **游标语义**：`cursor_index` 是「全字母序 S-位置」，不是新词序号。只在同步脚本确认导出后推进
  （= 本次新词的最大 S-位置 + 1）。**不要手动改**，否则会漏词或重复。
- **幂等安全**：某词当天 `last-review` 已等于 session 日期 → 同步脚本自动跳过，重复跑 sync 不会出错。
- **到期复习词**：`reviews>0 且 due<=当天`，每次实时现算，不要依赖 progress 历史里的日期推算。
- **每日上限 30**（`progress.json.dailyMaxWords`）：复习词 ≥ 30 时当天纯复习、不引入新词；剩余复习词
  `due` 不变，自动排到之后，不会丢。
- **挖空题**：构建期用 `deepseek-v4-flash` 生成（非思考模式），同词同日走缓存；无 key / 失败 /
  例句没含原形 → 该词静默跳过挖空，不阻塞背词。
- **挖空兜底（校园网等场景 API 不稳）**：构建后若发现例句缺失，由 Agent 直接生成双语例句写入
  `sync/cloze_cache.json`（key=word，格式 `{sentence_en, sentence_zh}`，英文句必须含该词【原形】，
  整词匹配 `\bword\b`），再重跑 `python3 build_review.py --date 同一天` 即可补齐，不依赖 API。
- **别在用户背词时重新 build**：`review.html` 是当天正在用的页面，等用户导出 session 后再生成明天的覆盖它。
- **key 安全**：`config.local.json` 里的 DeepSeek key 只存在于本地，不注入 HTML、不提交 git。
